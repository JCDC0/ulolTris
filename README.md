# ulolTris

A cozy block stacker for the browser, inspired by TETR.IO. Plain JavaScript, pixel art scenes, and sound made entirely with Web Audio.

Play: https://jcdc0.github.io/ulolTris/

## Modes

- 40 Lines: clear 40 lines as fast as you can.
- Blitz: score as much as you can in two minutes.
- Casual: endless play. The scene changes with each level.

## Controls

| Action | Keyboard | Touch |
|---|---|---|
| Move | Left, Right | Arrow buttons |
| Soft drop | Down | Down button |
| Hard drop | Space | DROP |
| Rotate right | Up or X | Right rotate button |
| Rotate left | Z | Left rotate button |
| Hold | C or Shift | HOLD |
| Pause | Esc | Pause button |

Touch buttons appear on phones and tablets. Settings > GAME > TOUCH CONTROLS can force them on or off.

## Run locally

```bash
npm install
npm run serve   # http://localhost:8123
npm test
```
